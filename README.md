### 🦉 Sokrat Study — my main project

An interactive learning platform (flashcards · quizzes · fill-in-the-blank · interactive exercises), **live and used by students at my faculty**.

🌐 **[sokratstudy.com](https://www.sokratstudy.com)**

- **22 subjects** across a multi-program catalog, with **HR/EN** internationalization
- Email **auth** + cloud progress sync, offline-first **PWA** (service worker)
- Built in **vanilla JavaScript — no framework, no build step** (fast &amp; simple by design)
- **Supabase** backend: PostgreSQL + Auth + Row-Level Security + Edge Functions
- Deployed on **Vercel**, with **Playwright** end-to-end tests running in **GitHub Actions** CI on every push
- In-browser content editor with a **draft → publish** workflow

> I designed, built, and run the whole thing myself — frontend, database, auth, deploy, and tests.
